Security & Architecture

  • Runs on Atlassian: 100% native Forge runtime (nodejs22.x) and Forge SQL. Zero external servers and zero outbound external.fetch declarations.
  • Parameterized SQL: All Forge SQL queries use sql.prepare(...).bindParams(...) with positional parameters.
  • Least-Privilege Scopes: Strictly limited to Confluence page/space/user read & write scopes plus read-only Jira work status lookup.
  • Auditability: All bulk actions generate immutable audit log entries exportable as CSV.
